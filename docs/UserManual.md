# BabyBlooming User Manual

Welcome to **BabyBlooming**, the streamlined tracking application for mindful caregivers.

## 🚀 Quick Start
1. **Prerequisites**: Ensure you have [Node.js](https://nodejs.org/) installed.
2. **Setup**: Run `npm install` in your terminal to fetch dependencies.
3. **Launch**: Execute `npm run dev` to start the local development server.
4. **View**: Open [http://localhost:3000](http://localhost:3000) in your web browser.

## 👶 Core Features
- **Growth Tracker**: Log weight, height, and head circumference over time.
- **Activity Logs**: Keep a digital record of feedings, sleep cycles, and diaper changes.
- **Insights**: View data-driven trends to better understand your infant's routines.

## 🛠 Troubleshooting
- **Blank Screen**: Open your browser's Developer Tools (F12). If you see Firebase errors, ensure your API keys are correctly set in the `.env` file.
- **Server Errors**: Ensure no other process is using port 3000.
